## Features

- Browse a curated list of emojis
- Copy emojis to clipboard with one click
- Clean and minimal UI
- Works on desktop and mobile
- No tracking, no ads

## Tech Stack

- Astro
- Tailwind CSS
- Vanilla JavaScript
- Clipboard API

## Local Development

```bash
git clone https://github.com/evnbnet/emoji-selector.git
cd emoji-selector
npm install
npm run dev
```
